# CONTENT QUALITY CHECKLIST — QUICK REFERENCE

**Use this after every lesson migration as final acceptance criteria**

## ✅ CONTENT QUALITY (10 items)

- [ ] Learning objectives clearly stated (min 5)
- [ ] Clear lesson progression (simple → complex)
- [ ] Concepts explained before tools
- [ ] Practical application included
- [ ] Knowledge checks test understanding (min 3 MCQs/section)
- [ ] Technical information is correct
- [ ] Security guidance is responsible
- [ ] External references are valid

- [ ] Depth provided for advanced learners

## ✅ VISUAL QUALITY (10 items)

- [ ] Premium hero section with metadata
- [ ] Consistent glassmorphism UI
- [ ] Educational diagrams created (SVG/CSS)
- [ ] No stock images
- [ ] Responsive layout (mobile → desktop)
- [ ] LessonCard used for sections
- [ ] InfoCard used appropriately (info/tip/warn/danger)
- [ ] TerminalBlock for commands (with copy buttons)
- [ ] ConceptGrid for related concepts
- [ ] LearningObjective card present
